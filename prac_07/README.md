## 🧹 Clean Code Lessons Learned

- Use **meaningful variable and function names** that clearly describe their purpose.
- Keep functions **short, focused**, and follow the **Single Responsibility Principle**.
- Follow consistent **code style** and **formatting** (e.g., PEP8 and auto-formatting tools).
- Always **close files properly**, or better yet, use `with` statements for file handling.
- Document code and write helpful **docstrings** and **comments** for clarity.
